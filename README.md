# -Walmart-Sales-Data-Analysis-Dashboard-Power-BI-
Interactive Power BI dashboard for analyzing Walmart sales data, revenue trends, customer purchasing behavior, product performance, and regional sales insights using dynamic visualizations and business intelligence.

📌 Project Overview

This project analyzes Walmart sales data using Power BI to uncover sales trends, customer purchasing patterns, product performance, and regional business insights. The interactive dashboard helps stakeholders monitor key performance indicators (KPIs), identify top-performing products, and make data-driven business decisions to improve sales and profitability.

🎯 Objectives
Analyze overall sales performance.
Monitor revenue and profit trends.
Identify top-selling products and categories.
Compare sales across branches and regions.
Understand customer purchasing behavior.
Support strategic business decisions with interactive dashboards.
